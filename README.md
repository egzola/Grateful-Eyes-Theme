# Grateful Eyes Theme 👁️👁️

A calm and stylish dark theme for Visual Studio Code, designed to be easy on the eyes and beautiful in every language.

![irritated eyes](https://i.imgur.com/kMY7JnX.png)

---

## Features

- Dark, elegant color scheme
- Optimized for long coding sessions
- Clear contrast between code types
- Supports most common programming languages

---

## Installation

1. Open **Extensions** panel in VS Code (`Ctrl+Shift+X`)
2. Search for `Grateful Eyes Theme`
3. Click **Install**
4. Go to **Preferences > Color Theme** and select `Grateful Eyes Theme`
